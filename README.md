# Copilot CLI Setup Check

Thanks for checking your setup before the workshop! This takes about 5 minutes.

## Run the check

1. In the terminal at the bottom of this window, type:

       copilot

2. If asked to trust the files in this folder, select **Yes**.
3. If asked to sign in, follow the prompts to log in with your GitHub account.
4. Type `/model` and press **Enter**.

## You're ready if...

- Copilot started without errors
- You signed in successfully
- You saw a list of available models after typing `/model`

Type `/exit` to close Copilot.

## Clean up

You won't need this Codespace again. To delete it, go to
[github.com/codespaces](https://github.com/codespaces), click the **...** menu
next to this Codespace, and select **Delete**.

## Something didn't work?

Reply to the workshop email with a screenshot of the error and I'll help
you sort it out before the session.
